# El Club dels Nombres Naturals

Vuit activitats interactives en català per a 1r d’ESO: bingo, mercat, dòmino, illa del tresor, nombre misteriós, cursa, fàbrica de nombres i detectius.

Web: https://jjbavatares.github.io/club-nombres-naturals/

Els resultats només existeixen durant la sessió. Informe descarregable en PDF d’una pàgina. Després de consultar una pista hi ha dos intents; si fallen, es mostra la solució i es pot continuar. Les proves no assolides no compten com a encerts.

GitHub Pages: branca main, carpeta arrel. Tots els recursos necessaris són locals. Missió Orió s’obre en una pestanya nova.

Les il·lustracions de còmic s’han generat amb l’eina integrada de generació d’imatges; els originals en alta resolució es conserven al projecte local. El logotip és JJB Avatares con IA. Les fonts i PDF-lib inclouen les seves llicències a assets/ i vendor/.
